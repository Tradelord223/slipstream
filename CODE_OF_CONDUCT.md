# Code of conduct

Slipstream is built in the open, and everyone who takes part should be able to do so without harassment.

**We expect** kindness and patience, respect for differing views and experience, constructive feedback aimed at the work rather than the person, and taking responsibility when we get something wrong.

**We don't accept** harassment of any kind, sexualized language or imagery, personal or political attacks, trolling, publishing someone's private information without permission, or anything else that would be inappropriate in a professional setting.

**Where it applies:** issues, pull requests, discussions and any other project space, and when someone represents the project elsewhere.

**Reporting:** contact the maintainer privately through GitHub (the Security tab's private report form works for conduct reports too). Reports are handled confidentially. The maintainer may remove comments, commits or other contributions that break this code, and may ban people who repeatedly or seriously break it.

This code is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.
